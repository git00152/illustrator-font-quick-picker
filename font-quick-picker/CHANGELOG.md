# Changelog

バージョンは `CSXS/manifest.xml` の `ExtensionBundleVersion` / `Extension Version` を正とする。

## 0.2.0 - 2026-11-04

### 修正
- Illustrator の起動中に入れたフォントが「Adobe」と表示され、新着にも出なかった問題を修正（フォント一覧が変わったら、フォントファイルも差分で走査し直す）
- 設定ファイルの書き込み中に Illustrator が終了すると、お気に入り・非表示・最近使ったフォントが消えることがあった問題を修正（一時ファイルに書いてから置き換え、前回分を `.bak` に残す。パネルを閉じる直前の変更も保存する）
- フォント索引の作り直しなどでファミリーの名前の取り方が変わると、お気に入り・非表示が外れることがあった問題を修正（PostScript 名でたどり直す）
- 権利情報のリンクは http / https だけを開くように変更（フォントファイル内の URL に他の形式があっても開かない）
- Illustrator のテーマ（明るさ）を変えたときに、パネルの配色とプレビュー画像の文字色が追従するように修正
- 見本文字に特殊な改行文字（U+2028 / U+2029）が入ると Illustrator でのプレビュー作成が失敗した問題を修正
- グループ内のテキストを選択しているときも、パネルにフォーカスすると使用中のフォントへジャンプするように修正
- Illustrator でのプレビュー作成に一度失敗したフォントを、30 秒後に 1 回だけ作り直す

### 変更
- Illustrator でのプレビュー作成は、パネルにフォーカスかマウスポインタがあるときだけ行う。1 回の一時書類で 16 件まで作り、スクロールが 0.8 秒止まってから始める
- Illustrator のフォント一覧を 500 件ずつ取得し、進捗を表示する（大量のフォントで Illustrator が長く止まらないように）。件数が同じでも先頭・末尾のフォントが変われば取り直す
- 一覧の取得とフォントファイルの走査を同時に実行しないようにした
- 新着を「パネルが初めて見た日時」の順に変更。Adobe Fonts も新着に出る（この版より前から入っていたフォントはファイルの ctime で代用）
- プレビュー用に読み込むフォントファイルの上限を、40 件から合計 160MB に変更
- 適用結果などのメッセージを、4 秒間は件数表示で上書きしない
- 一覧の行を、内容が変わったときだけ作り直す（スクロール中に DOM を作り直さない）

### 追加
- ショートカット：Alt+F（お気に入り）、Alt+H（非表示）を検索欄でも使える。⌘1〜⌘7（Windows は Ctrl）でタブ切替
- テスト（`tests/`、非公開側のみ）

### 内部
- `main.js` から `cep.js`（CEP・Illustrator 呼び出し）、`store.js`（設定ファイル）、`preview.js`（プレビュー）を分離

## 0.1.3 - 2026-11-02

### 変更
- プレビュー画像のキャッシュ（`pv/`）に 75MB の上限を設定。超えたら最後に使った日時が古いものから削除する（これまでどおり 30 日使っていない画像も削除）
- 見本文字の入力中・文字サイズの変更中は、入力が 1.5 秒止まるまで（日本語入力は変換が確定するまで）Illustrator での描画を待ち、打ちかけの文字列の画像を作らないようにした

### 追加
- パネルメニュー「プレビュー画像のキャッシュを削除」

## 0.1.2 - 2026-11-02

### 変更
- Adobe Fonts のフォントファイルを一切読まないように変更（Adobe Fonts の規約 3.4(E)(5)(7) に従い、Adobe が提供する手段以外でアクセスしない）。追加スキャンフォルダに指定しても読まない
- パネルで直接描けない書体（Adobe アプリ専用の Adobe Fonts、合成フォント）のプレビューを、Illustrator に一時的な書類で描かせた画像で表示（キャッシュつき）
- Adobe Fonts の判定は「フォントファイルが見つからない書体」による推定に変更（ツールチップに明記）
- 和文の判定に Illustrator のフォント名と和文書体の命名規則を使用

- プレビューでブラウザが擬似的な太字・斜体を作らないよう、書体のウエイト・スタイルを指定

## 0.1.0 - 2026-11-02

※ この版の Release（ZXP）は取り下げ済み。Adobe Fonts のフォントファイルの名前テーブルを読む処理を含むため。0.1.2 以降を使用すること。

最初の試作版。

### 一覧・検索
- インストール済みフォントをファミリー単位で一覧表示（仮想スクロール、表示中の行だけフォントを読み込み）
- 和名・英名・PostScript名・提供元名の横断検索（空白区切りで AND、全角/半角・ひらがな/カタカナを同一視）
- プレビュー表示／フォント名だけのコンパクト表示の切り替え
- 見本文字の変更、選択中テキストの取り込み、既定に戻す
- ウエイトをアコーディオンで展開して選択（↑↓ でウエイト移動、→← で開閉）

### 絞り込み・分類
- タブ：すべて／和文／欧文／合成／★／最近使用／新着（インストール日時が新しい順に最新50ファミリー）
- 欧文を Serif・Sans・Slab・Script・Mono・Display・Symbol に分類（OS/2 sFamilyClass → PANOSE → 名前）
- お気に入り、不要なフォントの非表示と再表示

### 適用
- テキスト選択中はクリックでそのまま適用（設定でダブルクリック適用に切り替え可）
- 適用後に Illustrator 側の結果を読み戻して確認し、適用されなかった場合は通知
- パネルにフォーカスしたとき、選択中テキストのフォントへジャンプ

### 提供元と権利情報
- 提供元バッジ：Adobe／モリサワ／Google／OFL／Ai同梱／macOS／他／?
- 同名フォントが複数の提供元から入っている場合の警告
- バッジのツールチップに用途別の権利情報（2026-11-02 時点、出典リンクつき）

### その他
- パネルメニュー：追加スキャンフォルダ、再スキャン、パネルを再読み込み（開発用）
- パネルサイズの上限を拡大
- 拡張 ID は `com.git00152.fontquickpicker`
- Adobe Fonts のフォントは名前のテーブルだけを読み、プレビューは OS に登録済みのフォントとして表示（ファイル全体は読み込まない）
